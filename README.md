# masker_AndroidWatch

اپلیکیشن Wear OS همراه برنامه گوشی [MaskerWithHeadphone_16Band](https://github.com/alireza-kha/MaskerWithHeadphone_16Band).
فقط بخش «ماسکر نویزی» آن برنامه (نویز ۱۶ باند شکل‌داده‌شده بر اساس اودیوگرام، حذف فرکانس
وزوز/Notch و مدولاسیون دامنه ۱۰ هرتز) را روی ساعت شبیه‌سازی می‌کند.

## نحوه کار

- موتور صدا (`app/src/main/java/com/masker/app/watch/audio`) و منطق محاسبه شدت باندها از
  روی اودیوگرام (`.../audiogram`) دقیقاً پورت‌شده از برنامه گوشی هستند تا صدای تولیدشده
  روی ساعت با گوشی یکسان باشد.
- تنظیمات (۱۶ باند، ولوم‌ها، نوچ، مدولاسیون) و آخرین اودیوگرام کاربر از برنامه گوشی از طریق
  **Wear Data Layer API** دریافت می‌شوند (`.../sync`). گوشی این‌ها را در یک DataItem واحد
  (مسیر `/masker/state`) منتشر می‌کند و ساعت هر بار تغییری برسد بلافاصله آن را روی موتور
  صدای در حال پخش اعمال می‌کند. ساعت هم می‌تواند با یک پیام (`/masker/request_sync`) از
  گوشی بخواهد فوراً وضعیت فعلی را دوباره بفرستد.
- روی ساعت به‌جای ۱۶ اسلایدر گوشی، یک کنترل ساده وجود دارد: دکمه پخش/توقف، ولوم کلی، وضعیت
  همگام‌سازی، و توگل نوچ/مدولاسیون. شدت هر باند و فرکانس/پهنای نوچ همیشه از آخرین مقدار
  رسیده از گوشی است.
- کد نظیر سمت گوشی (ارسال DataItem و پاسخ به درخواست همگام‌سازی) در پوشه
  `com.masker.app.wearsync` در ریپوی `MaskerWithHeadphone_16Band` اضافه شده است.

## بیلد

پروژه با Gradle استاندارد اندروید ساخته می‌شود (بدون Gradle Wrapper کامیت‌شده؛
`.github/workflows/main.yml` هنگام CI آن را می‌سازد):

```
gradle wrapper --gradle-version 8.6
./gradlew assembleDebug
```
